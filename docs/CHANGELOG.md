# 更新の記録

このアプリの変わったところです。

## 2026-11-15
- 時間を決めてとりくめるようになりました（1分・2分など。時間になると終わります）
- かけ算で、れんしゅうする だん（7のだん など）をえらべるようになりました
- タイムが1分をこえると「2分5.3秒」のように、分と秒で出るようになりました
- とりくんでいる間はタイムを出さない「タイマーを かくす」設定を足しました
- iPad をたてに持ったとき、手書きの線が太くて読みとれないことがあったのを直しました
- 100問なら、左の数に 0〜9 が1回ずつ出るようになりました
- 「すぐ判定」を切ったとき、全部入れても終われないことがあったのを直しました
- マスを飛ばして解くと、正解した答えが消えることがあったのを直しました
- 手書き入力に、マスを押さなくても進める「次へ」ボタンを足しました
- 「すぐ判定」を切ったときに使う「丸つけ する」ボタンを足しました
- 矢印キーで、飛ばしたマスへ戻れないことがあったのを直しました
- 1回開いたあとは、インターネットが無くても手書きが使えるようになりました
- 回線がおそいとき、画面がなかなか出ないことがあったのを直しました
- はじめて開いたときに、マスが出るまでの時間を短くしました
- 記録を保存できない端末で、画面が真っ白になることがあったのを直しました
