## note に貼る手順

1. note の新規記事を開き、1行目にタイトルを入れる。本文の `# ` から始まる行がタイトルです。この行は本文には貼らない
2. `## ` から始まる見出しは、note のエディタで「見出し」として入れ直す。note は見出しから目次を自動で作るので、ここが記事の骨格になります
3. 本文をそのまま貼る。太字も表も使っていないので、貼り付けで崩れるところはありません
4. 画像は自動で入りません。`images/` の中のファイルを、本文の `![...](images/xx-....png)` が置いてある位置に手でアップロードする
5. 画像の下に付いている一行の説明は、note のキャプション欄に移す。本文からは消す
6. `https://online-100square-calculation.giga-school.com/` の行は、note に貼ると自動でリンクカードになります。カードにしたくなければテキストリンクに変えてください
7. ハッシュタグは本文の最後の行にそのまま入っています。note のハッシュタグ欄に移してもかまいません

撮影に使ったシナリオは納品時に消してあります。作り直すときに気をつけるところ。

- **ファイル名を変えない。** 本文の参照が切れます。番号と本文の順番はもうずれていますが、それでかまいません

- **わざと数問まちがえる。** 全問正解だと「一発で正解できた率」が100%になり、「よく間違えた計算」が何も出ません
- **記録画面は、先に何回か解いてから開く。** 空の記録画面には見せるものがありません
- **手書きの画面は、指を離す前に撮る。** 離すと 0.4 秒後に読み取りが走り、線が消えます

## 文体について踏襲したこと

`references/style.md` の指定に合わせてあります。

- 太字、斜体、表、区切り記号を本文に使っていない。Markdown は見出しだけ
- 箇条書きは「📖【利用者向け】使い方のガイド」の番号つき手順だけ
- 専門用語を日常の言葉に置きかえた。手書きの読み取りのしくみ、記録の保存先、先読みの量など、名前を出さずに書いている
- 絵文字は見出しだけ
- 子どものことは「子どもたち」、読み手は「先生」「先生方」
- 見出しは基本の7つに、2つ足した形。足したのは「✍️ 手書き、テンキー、キーボードを1つのアプリの中で切り替える」と「🧠 『毎日おなじ計算をくり返して、意味があるのか』」で、どちらも 📱 と ✨ のあいだに置いてある

- 結びは #9 と同じ「一歩踏み出そうとする先生を、私はいつでも全力で応援しています。」

守ったことのうち、とくに注意したところ。

- **既存のアプリを名指ししていない。** 書いてあるのは「そういうものが多いと感じていました」という書き手の見立てまでです。どのアプリが、という話にはしていません
- **教室での出来事を実体験として書いていない。** この記事は作者の実践記録ではないので、「使ってみたら子どもたちが〜」は書けません。書いてあるのは「こうなればいいと思って作った」までです
- **効果を言い切っていない。** 「〜だと思います」「〜ではないかと思っています」の形にしてあります
- **批判への反論を、研究の引用で押していない。** 「🧠」の節は、100マス計算に向けられる批判に答えるところですが、出典を並べて論破する形にはしていません。ワーキングメモリという語も使わず、「頭の場所が空く」と書いています
