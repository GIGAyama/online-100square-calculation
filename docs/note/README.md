## note に貼る手順

1. note の新規記事を開き、1行目にタイトルを入れる。本文の `# ` から始まる行がタイトルです。この行は本文には貼らない
2. `## ` から始まる見出しは、note のエディタで「見出し」として入れ直す。note は見出しから目次を自動で作るので、ここが記事の骨格になります
3. 本文をそのまま貼る。太字も表も使っていないので、貼り付けで崩れるところはありません
4. 画像は自動で入りません。`images/` の中のファイルを、本文の `![...](images/xx-....png)` が置いてある位置に手でアップロードする
5. 画像の下に付いている一行の説明は、note のキャプション欄に移す。本文からは消す
6. `https://gigayama.github.io/online-100square-calculation/` の行は、note に貼ると自動でリンクカードになります。カードにしたくなければテキストリンクに変えてください
7. ハッシュタグ欄の案。`#GIGAスクール` `#小学校` `#算数` `#100マス計算` `#ICT教育` `#教育アプリ`

## 撮り直すときの手順

撮影の土台は `note-article` スキルの `scripts/` にあります。

```bash
npm i --no-save playwright
npm run build
node <skill>/scripts/serve.mjs dist 4180 /online-100square-calculation/
node <skill>/scripts/capture.mjs <シナリオ> --base http://127.0.0.1:4180/online-100square-calculation/ --out shots
```

撮影に使ったシナリオは納品時に消してあります。作り直すときに気をつけるところ。

- **解く速さを実時間に合わせる。** 1マス 30 ミリ秒で自動入力すると、記録画面に「100問 14.8秒」というありえないタイムが並びます。1マス 1.3〜1.6 秒にすると、100問で3分半あたりに落ち着きます
- **わざと数問まちがえる。** 全問正解だと「一発で正解できた率」が100%になり、「よく間違えた計算」が何も出ません。くり上がりのある式を狙って外すと、それらしい一覧になります
- **記録画面は、先に何回か解いてから開く。** 空の記録画面には見せるものがありません
- **手書きの画面は、指を離す前に撮る。** 離すと 0.4 秒後に読み取りが走り、線が消えます
- **印刷の画面は幅 703px で撮る。** A4 縦の印刷可能幅です。1366px のまま印刷のスタイルだけ当てても、紙で起きることは再現しません
- ボタンにはふりがなが入っています。文字で押すときは `<rt>` を落としてから比べてください。`capture.mjs` の `click()` はそうしてあります

## 文体について踏襲したこと

`references/style.md` の指定に合わせてあります。

- 太字、斜体、表、区切り記号を本文に使っていない。Markdown は見出しだけ
- 箇条書きは手順のところだけ。それ以外は文章
- 専門用語を日常の言葉に置きかえた。手書きの読み取りのしくみ、記録の保存先、先読みの量など、名前を出さずに書いている
- 絵文字は見出しだけ
- 子どものことは「子どもたち」、読み手は「先生」「先生方」
- 見出しは基本の6つに、目玉を2つ足した形。足したのは「✍️ 指で数字を書いて答える」と「📊 タイムより『一発で正解できた率』を見てください」
- 「導入のメリット」は「三つのいいことが期待できます。」から始める型
- 結びは #9 と同じ「一歩踏み出そうとする先生を、私はいつでも全力で応援しています。」

守ったことのうち、とくに注意したところ。

- **教室での出来事を実体験として書いていない。** この記事は作者の実践記録ではないので、「使ってみたら子どもたちが〜」は書けません。書いてあるのは「こうなればいいと思って作った」までです
- **効果を言い切っていない。** 「〜だと思います」「〜ではないかと思っています」の形にしてあります
- まとめの最後に「教室で使ってみないと分からないことが残っている」と書いてあります。実際の授業での様子は、書き手が自分で足すところです

## 撮影のあいだに見つかった不具合

ありません。19点すべて、記事に載せた機能を実際に操作して撮っています。手書きの読み取り、提示モード、印刷、記録、中断、すぐ判定の切り替え、入力ツールの左右の入れかえまで通して踏みました。

撮影のために一時的に当てた変更もありません。接続先の差しかえも、`/etc/hosts` の書きかえも使っていないので、`git status` にはこのフォルダの追加しか出ません。
