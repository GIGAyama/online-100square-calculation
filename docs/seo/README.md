## ⚠️ 公開前に必ず読むところ

**「教室で起きること」の節は、書き手が自分の実践で差し替える枠です。**

依頼の構成には「実践エピソード・子どもの変容」が入っていますが、**この記事の書き手はアプリの制作者であり、学級での実践記録として書けることがまだありません**。ここに作り話の子どものエピソードを置くと、記事の信頼性を根元から壊します（`docs/note/README.md` の「教室での出来事を実体験として書いていない」と同じ理由です）。

そこで、いまは次の形にしてあります。

- 「まだ語れる立場にない」と**先に明示**する
- **設計しながら期待していたこと**（先生の手が空く／教室を歩ける）を、予想として書く
- **まだ分かっていないこと**（10問きざみの妥当性、1年生の字の読み取り、担任がどこまで記録を見たくなるか）を並べる

実際に教室で使ったあと、**子どもの言葉・教室の空気・うまくいかなかった日**を1つか2つ入れて差し替えてください。**この記事がいちばん強くなるのはそこです。** 該当箇所には HTML コメントで目印を置いてあります（`⚠️ ここは書き手が自分の実践で差し替える枠です`）。
